# 26秋每周资讯推送实施计划

**目标：** 将已批准的7组资讯转换为7篇周报，新增归档菜单，验证后提交并推送。

**设计：** `docs/superpowers/specs/2026-11-06-weekly-2026-autumn-design.md`

**实现方式：** 本任务为已授权的内容迁移，由当前会话顺序执行；复用现有 Hugo Markdown、Front Matter、周报信息块和菜单配置。

## 全局约束

- 附件倒序还原，文章依次写入 `content/post/weekly-2026-autumn-01/index.md` 至 `07/index.md`。
- 发布时间分别为2026年9月7日、9月14日、9月21日、10月12日、10月19日、10月26日、11月2日，均为北京时间08:00。
- 分类和标签均为“26秋每周资讯推送”；`tocNumber: false`、`weeklyNews: true`。
- 保留所有原始条目和解读，仅调整结构、空白、链接协议及追踪参数。

## 执行与检查

- [x] 解析附件，验证7组各含5条行业和5条学术资讯，分别配对解读及特别推荐。
- [x] 生成7个 Markdown 页面包；套用26春的标题、无序清单、导读块及第二条后的摘要边界。
- [x] 修改 `hugo.yaml`：将新分类放在归档首位，现有分类顺序后移。
- [x] 将每个生成条目的标题、解读和规范化URL与附件逐一比对；检查倒序、停更日期、显式链接与特殊字符。
- [x] 运行 `hugo --gc --minify`，检查7篇生成页面、分类页、菜单、预览边界及信息块，抽查桌面与移动布局。
- [ ] 运行 `git diff --check`，检查修改范围，创建 Conventional Commit，推送 `origin/main`，核验远程提交。

## 重点复核

- 分行网址和没有 `https://` 的网址均能正常转换。
- `导读：` 前缀移到信息块标题，正文不重复。
- 特别推荐单独列出，条目前不残留“【特别推荐】”。
- 同一篇文献或行业报道在不同周重复出现时，忠实保留其各周版本。
- 源文件及新生成页面没有 ChatGPT 追踪参数和暴露的 Markdown 标记。
